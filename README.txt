Tutu Travel Club

Чтобы открыть приложение, запустите файл index.html в браузере.

Структура проекта:
- index.html — приложение;
- assets/ — изображения, SVG-карточки, иконки и шрифты.

Интернет-соединение для работы прототипа не требуется.

Полноэкранный режим на смартфоне:
- откройте опубликованный сайт по HTTPS;
- на iPhone выберите «Поделиться» → «На экран Домой»;
- на Android выберите «Установить приложение» или «Добавить на главный экран»;
- запускайте Tutu Club с появившейся иконки — приложение откроется без адресной строки браузера.
